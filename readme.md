2. CURSOR TRACKING SYSTEM
   Tambahkan sistem cursor tracking yang terlihat selama proses pembangunan website.
   Ketentuannya:

- Gunakan custom cursor berbentuk pointer atau developer cursor.
- Cursor bergerak mengikuti elemen yang sedang dibangun.
- Ketika navbar dibuat, cursor bergerak ke area navbar.
- Ketika Hero Section dibuat, cursor bergerak menuju elemen yang sedang dimunculkan.
- Ketika section baru dibangun, cursor bergerak mengikuti proses tersebut.
- Tambahkan efek visual kecil ketika cursor melakukan klik.
- Berikan efek garis atau lingkaran halus di sekitar cursor.
- Gerakan cursor harus natural, smooth, dan tidak kaku.
- Tambahkan trail atau jejak cahaya yang halus.
  Pastikan cursor tracking hanya menjadi elemen visual dan tidak mengganggu interaksi pengguna.
  Pada perangkat touchscreen, nonaktifkan custom cursor dan gunakan animasi pembangunan yang sama tanpa cursor.
